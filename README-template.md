## My process
I first created the structure of the recipe page using HTML and then styled the page with CSS to match the provided design. I focused on getting the layout, fonts, colors, spacing, and typography as close to the original design as possible.

While working on this project, I practiced using semantic HTML, Flexbox, CSS spacing, Google Fonts, and responsive design. I also used Git and GitHub to keep track of my progress and publish my solution.

### Built with

- Semantic HTML5 markup
- CSS custom properties
- Flexbox
- CSS Grid

### What I learned

While working on this project, I learned how important semantic HTML is for accessibility and how CSS can be used to closely match a design. I also got more comfortable with spacing, typography, colors, and Flexbox. This project also gave me more practice using Git, making commits, and pushing my work to GitHub.

### Continued development
I plan to continue improving my CSS skills by practicing responsive design and creating more projects. I also want to become more comfortable with Flexbox and other CSS layout techniques as I work on future projects.
